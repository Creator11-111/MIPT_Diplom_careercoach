# Синхронизация с GitHub

## Автоматическая синхронизация

После каждого коммита изменения автоматически отправляются в GitHub через Git hook.

## Ручная синхронизация

**Просто дважды кликните на файл `push_to_github.bat`** в папке `financial_coach`.

Этот скрипт:
1. Проверит статус изменений
2. Добавит все изменения
3. Создаст коммит
4. Отправит в GitHub (ветка `diploma-version`)

## Первая синхронизация (сейчас)

Запустите `push_to_github.bat` для отправки всех текущих изменений.
