# Интеллектуальная система карьерного коучинга для финансового сектора

Выпускная квалификационная работа (ВКР) МФТИ

## Описание проекта

Система представляет собой веб-приложение для карьерного консультирования специалистов финансового и банковского сектора. Приложение использует технологии искусственного интеллекта (LLM) и семантический поиск для персонализированного подбора вакансий, курсов и построения карьерных траекторий.

## Основные возможности

- **Интеллектуальное интервью**: Диалог с AI-консультантом для сбора информации о профессиональном опыте, навыках и карьерных целях
- **Поиск вакансий**: Семантический поиск релевантных вакансий с HeadHunter.ru с использованием FAISS и двухэтапной фильтрации через LLM
- **План развития карьеры**: Анализ разрыва между текущей и желаемой позицией, подбор курсов и вакансий для роста
- **Управление сессиями**: Сохранение истории диалогов, возможность создания нескольких сессий
- **Экспорт данных**: Выгрузка истории чата в форматах PDF и Word

### Компоненты системы

#### 1. Frontend (Веб-интерфейс)

**Файл**: `static/index.html`

Веб-интерфейс реализован как одностраничное приложение (SPA) на чистом JavaScript. Основные компоненты:

- **Боковая панель**: Управление сессиями чата, создание новых сессий, удаление
- **Область чата**: Отображение диалога с AI-консультантом
- **Карточки вакансий**: Визуализация найденных вакансий с возможностью раскрытия описаний
- **Модальные окна**: Форма для запроса плана развития карьеры

**Ключевые особенности реализации**:
- Асинхронная загрузка данных через Fetch API
- Управление состоянием через localStorage (sessionId, userId)
- Защита от двойной отправки сообщений (флаг `isSending`)
- Автоматическая прокрутка к важным разделам (вакансии, план развития)

#### 2. API Layer (FastAPI)

**Файл**: `app/main.py`

FastAPI приложение с модульной структурой роутеров:

- **`/sessions`**: Управление сессиями (создание, получение, список, удаление, экспорт)
- **`/chat/{session_id}`**: Обработка сообщений в чате
- **`/profile/{session_id}`**: Построение структурированного профиля из диалога
- **`/match/vacancies/by-session/{session_id}`**: Поиск вакансий на основе профиля
- **`/match/career-development`**: Генерация плана развития карьеры

**Инициализация приложения**:
- Подключение к MongoDB при старте
- Построение FAISS индексов для семантического поиска
- Загрузка вакансий в базу данных (если отсутствуют)

#### 3. Business Logic Layer

##### ChatService (`app/services/chat_service.py`)

Отвечает за ведение диалога с пользователем:

1. **Сбор контекста**: Получение последних 40 сообщений из истории сессии
2. **Формирование промпта**: Добавление системного промпта с инструкциями для AI
3. **Генерация ответа**: Вызов YandexGPT с JSON-схемой для структурированного ответа
4. **Определение завершенности**: Анализ флага `done` для определения окончания интервью

**Логика интервью**:
- AI задает вопросы последовательно (один вопрос за сообщение)
- Нумерация вопросов (1 из 10, 2 из 10 и т.д.)
- Сбор информации о профессиональном опыте, навыках, целях
- Автоматическое определение момента завершения интервью

##### MatchService (`app/services/match_service.py`)

Реализует многоэтапный поиск вакансий:

**Этап 0: Препроцессинг резюме**
- Обогащение резюме ключевыми словами через LLM
- Добавление финансовых терминов, инструментов, сертификатов
- Улучшение семантического поиска

**Этап 1: Семантический поиск (FAISS)**
- Создание эмбеддинга запроса через YandexGPT Embeddings API
- Поиск топ-K похожих вакансий в FAISS индексе
- Возврат 100 наиболее релевантных кандидатов

**Этап 2: Фильтрация по названиям (LLM Stage 1)**
- Формирование списка вакансий в формате "idx: название"
- Использование LLM для отбора 30 лучших по названиям
- Учет финансовой специфики и уровня позиции

**Этап 3: Финальный отбор (LLM Stage 2)**
- Детальный анализ описаний вакансий
- Сопоставление с резюме пользователя
- Финальный отбор 15 наиболее подходящих вакансий

**Определение уровня позиции**:
- Анализ названия, описания, требований к опыту
- Классификация: Стажер, Начальный, Средний, Продвинутый, Эксперт, Руководитель
- Использование ключевых слов и LLM для точной классификации

##### CareerDevelopmentService (`app/services/career_development_service.py`)

Строит план развития карьеры:

1. **Анализ разрыва (Gap Analysis)**:
   - Сравнение текущей позиции с желаемой
   - Выявление недостающих навыков и компетенций
   - Формирование списка пробелов для закрытия

2. **Подбор курсов**:
   - Генерация рекомендаций через LLM на основе gap analysis
   - Определение провайдера, уровня, языка курса
   - Построение корректных поисковых ссылок на платформы (Coursera, Stepik, Нетология и др.)

3. **Поиск вакансий роста**:
   - Формирование "будущего резюме" с учетом пройденных курсов
   - Поиск вакансий, доступных после развития навыков
   - Отображение промежуточных позиций на пути к цели

##### ProfileService (`app/services/profile_service.py`)

Преобразует диалог в структурированный профиль:

- Анализ всей истории сообщений через LLM
- Извлечение структурированных данных по JSON-схеме
- Формирование профиля с разделами: профессиональный контекст, опыт работы, навыки, цели

#### 4. Data Access Layer

Репозитории обеспечивают абстракцию над MongoDB:

- **SessionsRepository**: Управление сессиями чата
- **MessagesRepository**: Хранение и получение сообщений
- **ProfilesRepository**: Сохранение структурированных профилей
- **VacanciesRepository**: Доступ к вакансиям из базы данных
- **CoursesRepository**: Работа с курсами (если используется)

Все репозитории используют асинхронный драйвер Motor для работы с MongoDB.

#### 5. Data Storage Layer

##### MongoDB

Хранит:
- Сессии чата (session_id, user_id, состояние)
- Сообщения (role, content, timestamp, done flag)
- Профили пользователей (структурированные данные)
- Вакансии (название, описание, навыки, компания, локация, зарплата)
- Курсы (если используется)

##### FAISS

Индекс для быстрого семантического поиска:
- Хранение эмбеддингов вакансий
- Поиск похожих векторов за O(log n)
- Индекс строится при старте приложения из эмбеддингов в `data/embeddings/`

##### YandexGPT

Используется для:
- Генерации ответов в чате
- Структурированного извлечения данных (профили)
- Фильтрации вакансий и курсов
- Анализа разрывов в карьере

## Алгоритмы и методы

### 1. Семантический поиск вакансий

**Проблема**: Необходимо найти вакансии, релевантные резюме пользователя, учитывая семантическое сходство, а не только ключевые слова.

**Решение**: Комбинация векторного поиска (FAISS) и LLM-фильтрации.

**Алгоритм**:
```
1. Препроцессинг резюме:
   - Обогащение ключевыми словами через LLM
   - Добавление финансовых терминов, инструментов

2. Создание эмбеддинга:
   - Использование YandexGPT Embeddings API
   - Получение 768-мерного вектора

3. Поиск в FAISS:
   - Поиск топ-100 похожих вакансий
   - Использование L2-расстояния

4. Двухэтапная фильтрация LLM:
   - Stage 1: Отбор по названиям (100 → 30)
   - Stage 2: Отбор по описаниям (30 → 15)

5. Определение уровня позиции:
   - Анализ ключевых слов
   - Классификация через LLM при необходимости
```

**Обоснование выбора**:
- FAISS обеспечивает быстрый поиск по большим объемам данных
- LLM-фильтрация повышает точность за счет понимания контекста
- Двухэтапный подход балансирует скорость и качество

### 2. Построение профиля из диалога

**Проблема**: Необходимо извлечь структурированные данные из неструктурированного диалога.

**Решение**: Использование LLM с JSON-схемой для структурированного извлечения.

**Алгоритм**:
```
1. Сбор истории диалога:
   - Получение всех сообщений сессии
   - Формирование контекста для LLM

2. Определение JSON-схемы:
   - Структура профиля (профессиональный контекст, опыт, навыки, цели)
   - Обязательные и опциональные поля

3. Генерация структурированного профиля:
   - Вызов YandexGPT с JSON-схемой
   - Парсинг результата

4. Валидация через Pydantic:
   - Проверка типов и обязательных полей
   - Обработка ошибок
```

**Преимущества**:
- Гибкость: LLM адаптируется к различным форматам ответов пользователя
- Точность: Структурированная схема гарантирует корректность данных
- Масштабируемость: Легко добавить новые поля в профиль

### 3. Генерация плана развития карьеры

**Проблема**: Необходимо построить персональный план перехода от текущей позиции к желаемой.

**Решение**: Трехэтапный процесс: анализ разрыва → подбор курсов → поиск вакансий роста.

**Алгоритм**:
```
1. Gap Analysis:
   - Сравнение текущего профиля с требованиями целевой позиции
   - Выявление недостающих навыков, инструментов, опыта
   - Формирование списка пробелов

2. Подбор курсов:
   - Генерация рекомендаций через LLM на основе gap analysis
   - Определение провайдера, уровня, языка
   - Построение поисковых ссылок на платформы

3. Поиск вакансий роста:
   - Формирование "будущего резюме" с учетом пройденных курсов
   - Поиск вакансий через MatchService
   - Отображение промежуточных позиций
```

**Особенности реализации**:
- Учет финансовой специфики при анализе разрывов
- Валидация ссылок на курсы (только прямые ссылки, не поиск)
- Определение языка курса для удобства пользователя

## Установка и запуск

### Требования

- Python 3.12+
- MongoDB (локально или облачная версия)
- API ключ YandexGPT (Yandex Cloud)

### Шаг 1: Установка зависимостей

```bash
cd financial_coach
pip install -r requirements.txt
```

### Шаг 2: Настройка переменных окружения

Создайте файл `.env` в папке `financial_coach/`:

```env
# YandexGPT (обязательно)
YANDEX_FOLDER_ID=your_folder_id
YANDEX_API_KEY=your_api_key

# MongoDB
MONGO_URI=mongodb://localhost:27017
MONGO_DB=financial_career_coach

# Приложение
APP_ENV=development
APP_HOST=0.0.0.0
APP_PORT=8000
```

### Шаг 3: Подготовка данных

#### Парсинг вакансий с HeadHunter.ru

```bash
python data_parsing/scrape_financial_vacancies_hh.py
```

Скрипт собирает финансовые вакансии через официальный API HH.ru и сохраняет в `data/financial_vacancies.parquet`.

#### Генерация эмбеддингов

```bash
python data_parsing/generate_embeddings.py
```

Создает эмбеддинги для всех вакансий и сохраняет в `data/embeddings/vacancies/`.

### Шаг 4: Запуск приложения

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Приложение будет доступно по адресу: `http://localhost:8000`

Веб-интерфейс: `http://localhost:8000/static/index.html`

API документация: `http://localhost:8000/docs`

## API Endpoints

### Сессии

- `POST /sessions` - Создать новую сессию
- `GET /sessions` - Получить список сессий пользователя
- `GET /sessions/{session_id}` - Получить сессию с историей
- `DELETE /sessions/{session_id}` - Удалить сессию
- `GET /sessions/{session_id}/export?format=pdf|docx` - Экспорт истории

### Чат

- `POST /chat/{session_id}` - Отправить сообщение и получить ответ AI

### Профиль

- `GET /profile/{session_id}` - Построить структурированный профиль из диалога

### Поиск

- `POST /match/vacancies/by-session/{session_id}` - Найти вакансии для пользователя
- `POST /match/career-development` - Получить план развития карьеры

## Особенности реализации

### Асинхронность

Все операции с базой данных и внешними API выполняются асинхронно через `async/await`, что обеспечивает высокую производительность при множественных запросах.

### Защита от ошибок

- Валидация входных данных через Pydantic
- Обработка исключений на всех уровнях
- Fallback-механизмы (например, при недоступности FAISS)
- Информативные сообщения об ошибках

### Масштабируемость

- Модульная архитектура позволяет легко добавлять новые функции
- Разделение на слои упрощает тестирование и поддержку
- Использование репозиториев обеспечивает гибкость в выборе БД

## Производительность

- **FAISS поиск**: O(log n) для поиска похожих векторов
- **LLM фильтрация**: Двухэтапный подход балансирует качество и скорость
- **Асинхронность**: Параллельная обработка запросов
- **Кэширование**: Эмбеддинги вакансий вычисляются один раз при парсинге

## Безопасность

- API ключи хранятся в переменных окружения (не в коде)
- Валидация всех входных данных
