# Что делать после загрузки эмбеддингов

## Шаг 1: Проверка статуса

**Запустите файл `CHECK_EMBEDDINGS_STATUS.bat`** чтобы проверить:
- Были ли эмбеддинги закоммичены
- Отслеживаются ли они через Git LFS
- Отправлены ли они в GitHub

## Шаг 2: Проверка на GitHub

1. Откройте ваш репозиторий: https://github.com/Creator11-111/MIPT_Diplom_careercoach
2. Перейдите в папку `data/embeddings/vacancies/`
3. Откройте любой файл `.npy`
4. **Должно быть написано: "Stored with Git LFS"** (не обычный файл)

Если видите "Stored with Git LFS" - ✅ все отлично!

## Шаг 3: Деплой на Railway

После того как эмбеддинги загружены в GitHub:

1. **Railway автоматически задеплоит** при следующем push (если настроен автодеплой)
2. **Или запустите деплой вручную** в панели Railway

### Что должно произойти на Railway:

1. Railway загрузит код из GitHub
2. Выполнит `git lfs install && git lfs pull` (из `railway.json`)
3. Загрузит все эмбеддинги через Git LFS
4. Установит зависимости
5. Запустит приложение

### Проверка логов Railway:

После деплоя проверьте логи, должны увидеть:
```
✅ FAISS индекс построен: X вакансий
   Размерность векторов: 256
```

Если видите:
```
⚠️ Папка с эмбеддингами не найдена
```

Значит Git LFS файлы не загрузились. См. раздел "Проблемы" ниже.

## Шаг 4: Тестирование

После успешного деплоя:

1. Откройте ваш сайт на Railway
2. Начните диалог с коучем
3. Пройдите интервью
4. Попросите найти вакансии
5. **Если поиск работает быстро и находит релевантные вакансии** - все отлично! ✅

## Возможные проблемы

### Проблема 1: На GitHub файлы не отображаются как Git LFS

**Причина:** Эмбеддинги не были правильно добавлены в Git LFS

**Решение:**
1. Убедитесь, что `.gitattributes` содержит: `data/embeddings/**/*.npy filter=lfs diff=lfs merge=lfs -text`
2. Запустите заново `fix_and_upload_embeddings.bat`

### Проблема 2: На Railway эмбеддинги не загружаются

**Причина:** Railway не может загрузить Git LFS файлы

**Решение:**
1. Проверьте логи Railway - должны быть команды `git lfs install` и `git lfs pull`
2. Убедитесь, что в `railway.json` есть `buildCommand` с `git lfs pull`
3. Если не работает, можно сгенерировать эмбеддинги на Railway при первом запуске

### Проблема 3: GitHub LFS лимит превышен

**Причина:** Эмбеддинги слишком большие для бесплатного плана (1 GB)

**Решение:**
- Обновите GitHub до платного плана (50 GB)
- Или используйте альтернативный вариант: генерировать эмбеддинги на Railway

## Альтернативный вариант (если Git LFS не работает)

Если Git LFS не работает на Railway, можно:

1. **Генерировать эмбеддинги на Railway при первом запуске:**
   - Добавить в startup скрипт генерацию эмбеддингов
   - Это займет время при первом деплое, но будет работать

2. **Использовать внешнее хранилище:**
   - Загрузить эмбеддинги в S3/Google Cloud Storage
   - Загружать их при старте приложения
