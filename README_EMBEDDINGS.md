# Загрузка эмбеддингов через Git LFS

## Что такое Git LFS?

Git LFS (Large File Storage) - это расширение Git для работы с большими файлами. Эмбеддинги (2574 файла .npy) слишком большие для обычного Git, поэтому они хранятся через Git LFS.

## Текущая ситуация

- ✅ Git LFS установлен на вашем компьютере
- ✅ `.gitattributes` настроен для отслеживания `.npy` файлов
- ⏳ Эмбеддинги нужно загрузить в GitHub через Git LFS

## Загрузка эмбеддингов в GitHub

### Шаг 1: Запустите скрипт загрузки

**Дважды кликните на файл `upload_embeddings_lfs.bat`** в папке `financial_coach`.

Этот скрипт:
1. Проверит, что Git LFS установлен
2. Инициализирует Git LFS в репозитории
3. Добавит все эмбеддинги (2574 файла) в Git LFS
4. Создаст коммит
5. Отправит в GitHub

**⚠️ ВНИМАНИЕ:** Загрузка может занять 10-30 минут! Не прерывайте процесс.

### Шаг 2: Проверка на GitHub

После загрузки проверьте на GitHub:
- Перейдите в ваш репозиторий
- Откройте папку `data/embeddings/vacancies/`
- Файлы `.npy` должны отображаться как "Stored with Git LFS"

## Настройка Railway для работы с Git LFS

Railway автоматически загружает Git LFS файлы при деплое, **НО** нужно убедиться, что:

1. **Git LFS установлен в Railway:**
   - Railway использует Nixpacks для сборки
   - Git LFS должен быть установлен автоматически
   - Если нет, добавьте в `railway.json`:

```json
{
  "build": {
    "builder": "NIXPACKS",
    "buildCommand": "git lfs install && git lfs pull && pip install -r requirements.txt"
  }
}
```

2. **Проверка после деплоя:**
   - После деплоя на Railway проверьте логи
   - Должны увидеть: "✅ FAISS индекс построен: X вакансий"
   - Если видите "⚠️ Папка с эмбеддингами не найдена", значит Git LFS файлы не загрузились

## Альтернативный вариант (если Git LFS не работает на Railway)

Если Git LFS не работает на Railway, можно:

1. **Генерировать эмбеддинги на Railway при первом запуске:**
   - Добавить в `Procfile` или startup скрипт генерацию эмбеддингов
   - Это займет время при первом деплое, но будет работать

2. **Использовать внешнее хранилище:**
   - Загрузить эмбеддинги в S3/Google Cloud Storage
   - Загружать их при старте приложения

## Проверка работы

После загрузки эмбеддингов в GitHub и деплоя на Railway:

1. Откройте ваш сайт на Railway
2. Начните диалог с коучем
3. После завершения интервью попросите найти вакансии
4. Если поиск работает быстро и находит релевантные вакансии - все работает! ✅

Если поиск не работает или медленный - проверьте логи Railway на наличие ошибок загрузки эмбеддингов.
