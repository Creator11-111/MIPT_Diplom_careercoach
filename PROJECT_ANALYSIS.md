## 🗑️ Можно удалить (не критично)

### Пустые папки
- ⚠️ `docs/` - пустая папка (можно удалить вручную)
- ⚠️ `scripts/` - пустая папка (можно удалить вручную)

**Как удалить:**
```cmd
cd financial_coach
rmdir docs
rmdir scripts
```

Или просто игнорировать - они не занимают место и не мешают работе.

**Все важные файлы используются и необходимы для работы проекта.**
