# Настройка эмбеддингов для деплоя на Railway

## Что нужно сделать

### Шаг 1: Загрузить эмбеддинги в GitHub через Git LFS

1. **Откройте папку `financial_coach` в проводнике Windows**
2. **Дважды кликните на файл `upload_embeddings_lfs.bat`**
3. **Дождитесь завершения** (может занять 10-30 минут)
4. Скрипт автоматически:
   - Проверит Git LFS
   - Добавит все эмбеддинги (2574 файла)
   - Создаст коммит
   - Отправит в GitHub

### Шаг 2: Проверка на GitHub

После загрузки проверьте:
- Откройте ваш репозиторий на GitHub
- Перейдите в `data/embeddings/vacancies/`
- Файлы `.npy` должны отображаться как **"Stored with Git LFS"** (не обычные файлы)

### Шаг 3: Деплой на Railway

Railway автоматически:
1. Загрузит код из GitHub
2. Установит Git LFS
3. Загрузит эмбеддинги через `git lfs pull`
4. Установит зависимости
5. Запустит приложение

**Проверьте логи Railway после деплоя:**
- Должно быть: `✅ FAISS индекс построен: X вакансий`
- Если видите: `⚠️ Папка с эмбеддингами не найдена` - значит Git LFS файлы не загрузились

## Что уже настроено

✅ `.gitattributes` - настроен для отслеживания `.npy` файлов через Git LFS
✅ `railway.json` - обновлен для загрузки Git LFS файлов при сборке
✅ `load_embeddings.py` - автоматически найдет эмбеддинги на Railway

## Если что-то пошло не так

### Проблема: Git LFS не установлен
**Решение:** Установите с https://git-lfs.github.com/

### Проблема: Ошибка при загрузке в GitHub
**Возможные причины:**
- Недостаточно места в GitHub LFS (нужен платный план для больших файлов)
- Проблемы с интернет-соединением
- Проблемы с аутентификацией

**Решение:** 
- Проверьте лимиты GitHub LFS в настройках репозитория
- Попробуйте загрузить позже
- Проверьте аутентификацию GitHub

### Проблема: На Railway эмбеддинги не загружаются
**Решение:**
1. Проверьте логи Railway - должны быть команды `git lfs install` и `git lfs pull`
2. Убедитесь, что в GitHub файлы действительно хранятся через Git LFS
3. Если не работает, можно сгенерировать эмбеддинги на Railway при первом запуске (добавить в startup)

## Размер эмбеддингов

- **Количество файлов:** 2574 файла `.npy`
- **Общий размер:** ~200-500 MB (зависит от размерности векторов)
- **GitHub LFS:** Бесплатный план дает 1 GB, платный - 50 GB
