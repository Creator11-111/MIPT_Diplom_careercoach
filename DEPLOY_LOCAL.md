# Деплой с локального компьютера на Railway

## Подготовка

### 1. Установите Railway CLI

**Windows:**
```powershell
# Через PowerShell (от администратора)
iwr https://railway.app/install.ps1 | iex
```

**Или через npm:**
```bash
npm install -g @railway/cli
```

**Или через Scoop:**
```bash
scoop install railway
```

### 2. Авторизация в Railway

```bash
railway login
```

Откроется браузер для авторизации.

## Деплой

### Вариант 1: Деплой через Railway CLI (рекомендуется)

1. **Перейдите в папку проекта:**
   ```bash
   cd financial_coach
   ```

2. **Инициализируйте проект (если еще не инициализирован):**
   ```bash
   railway init
   ```
   Выберите существующий проект или создайте новый.

3. **Деплой:**
   ```bash
   railway up
   ```

   Railway CLI автоматически:
   - Определит тип проекта (Python)
   - Установит зависимости
   - Запустит приложение

### Вариант 2: Деплой через скрипт

**Запустите файл `deploy_to_railway.bat`** в папке `financial_coach`.

Скрипт автоматически выполнит все необходимые команды.

## Настройка переменных окружения

После первого деплоя настройте переменные окружения в Railway:

1. Откройте ваш проект в Railway Dashboard
2. Перейдите в Settings → Variables
3. Добавьте переменные:
   - `MONGO_URI` - строка подключения к MongoDB
   - `MONGO_DB` - название базы данных (например: `financial_career_coach`)
   - `YANDEX_FOLDER_ID` - ID папки Yandex Cloud
   - `YANDEX_API_KEY` - API ключ YandexGPT
   - `APP_ENV` - `production`

Подробные инструкции по получению этих переменных см. в `ENV_VARIABLES_GUIDE.md`.

## Загрузка эмбеддингов

Эмбеддинги находятся в папке `data/embeddings/vacancies/` на вашем компьютере.

### Вариант 1: Включить эмбеддинги в деплой

Railway CLI автоматически загрузит все файлы из папки проекта, включая эмбеддинги.

**⚠️ ВНИМАНИЕ:** Это может занять много времени и места (2574 файла, ~200-500 MB).

### Вариант 2: Генерировать эмбеддинги на Railway

Если эмбеддинги слишком большие, можно сгенерировать их на Railway при первом запуске:

1. Добавьте в startup скрипт генерацию эмбеддингов
2. При первом деплое эмбеддинги будут сгенерированы автоматически
3. Это займет время при первом запуске, но будет работать

## Проверка деплоя

После деплоя:

1. **Проверьте логи:**
   ```bash
   railway logs
   ```

2. **Откройте сайт:**
   ```bash
   railway open
   ```

3. **Проверьте работу:**
   - Начните диалог с коучем
   - Пройдите интервью
   - Попросите найти вакансии
   - Если поиск работает - все отлично! ✅

## Обновление деплоя

После внесения изменений в код:

1. **Запустите `deploy_to_railway.bat`** или выполните:
   ```bash
   railway up
   ```

2. Railway автоматически обновит деплой с новыми изменениями.

## Синхронизация с GitHub

Для синхронизации кода с GitHub (без деплоя):

**Запустите `push_to_github.bat`** - он отправит все изменения в GitHub.

## Полезные команды Railway CLI

```bash
# Просмотр логов
railway logs

# Открыть сайт в браузере
railway open

# Просмотр статуса
railway status

# Просмотр переменных окружения
railway variables

# Добавить переменную окружения
railway variables set MONGO_URI="your-uri"

# Подключиться к контейнеру
railway shell
```

## Решение проблем

### Проблема: Railway CLI не установлен

**Решение:** Установите Railway CLI (см. раздел "Подготовка")

### Проблема: Ошибка авторизации

**Решение:** Выполните `railway login` заново

### Проблема: Эмбеддинги не загружаются

**Решение:** 
- Проверьте, что папка `data/embeddings/vacancies/` существует
- Или используйте генерацию эмбеддингов на Railway

### Проблема: Приложение не запускается

**Решение:**
1. Проверьте логи: `railway logs`
2. Проверьте переменные окружения в Railway Dashboard
3. Убедитесь, что все зависимости установлены
