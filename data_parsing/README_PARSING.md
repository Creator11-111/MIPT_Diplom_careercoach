# 📋 Инструкция по парсингу финансовых вакансий

## 🎯 Что делает этот скрипт?

Скрипт `scrape_financial_vacancies_hh.py` собирает вакансии из финансового и банковского сектора с сайта HH.ru и сохраняет их в удобном формате для дальнейшей обработки.

## 🔧 Как это работает?

### Простыми словами:
1. **Подключаемся к API HH.ru** - это официальный способ получить данные о вакансиях
2. **Ищем вакансии** по финансовым категориям (финансовый аналитик, банковский специалист и т.д.)
3. **Собираем информацию** о каждой вакансии (название, описание, зарплата, навыки)
4. **Сохраняем в файл** в формате Parquet (это как Excel, но для больших данных)

### Технически:
- Используется библиотека `requests` для HTTP запросов
- API HH.ru возвращает данные в формате JSON
- Данные обрабатываются и сохраняются в Parquet через библиотеку `polars`

## 📦 Установка зависимостей

Перед запуском установите необходимые библиотеки:

```bash
pip install requests polars tqdm
```

Или если используете `requirements.txt`:

```bash
pip install -r requirements.txt
```

## 🚀 Как запустить?

### Вариант 1: Простой запуск (по всей России)

```bash
python financial_coach/data_parsing/scrape_financial_vacancies_hh.py
```

Это соберет вакансии по всей России (может занять 30-60 минут).

### Вариант 2: С ограничениями (быстрее, для тестирования)

Откройте файл `scrape_financial_vacancies_hh.py` и измените параметры:

```python
# В функции main() измените:
vacancies = scraper.scrape_all_financial_vacancies(
    area=1,              # 1 = Москва (быстрее)
    max_per_category=50   # Меньше вакансий на категорию
)
```

## ⚙️ Настройки

### Параметры поиска

В файле `scrape_financial_vacancies_hh.py` можно настроить:

1. **Регион поиска** (`area`):
   - `1` - Москва
   - `2` - Санкт-Петербург  
   - `113` - Вся Россия

2. **Количество вакансий** (`max_per_category`):
   - По умолчанию: 500 на категорию
   - Можно уменьшить для тестирования

3. **API токен** (опционально):
   - Если у вас есть токен от HH.ru, укажите его в `HHVacancyScraper(api_token="ваш_токен")`
   - Токен можно получить на https://hh.ru/oauth/applications
   - Без токена тоже работает, но могут быть ограничения по количеству запросов

## 📊 Результат

После выполнения скрипта создастся файл:

```
financial_coach/data/financial_vacancies.parquet
```

Этот файл содержит все собранные вакансии в структурированном виде.

## 📋 Структура данных

Каждая вакансия содержит:

- `idx` - уникальный ID (индекс)
- `title` - название вакансии
- `company` - название компании
- `location` - город
- `salary` - зарплата (если указана)
- `experience` - требуемый опыт
- `description` - описание вакансии
- `key_skills` - ключевые навыки
- `job_type` - тип работы (полная/частичная занятость)
- `date_of_post` - дата публикации
- `hh_url` - ссылка на вакансию на HH.ru

## ⚠️ Важные замечания

1. **Скорость запросов**: Скрипт делает задержки между запросами, чтобы не перегружать API HH.ru. Это нормально, если процесс идет медленно.

2. **Ограничения API**: HH.ru может ограничивать количество запросов. Если получаете ошибки - подождите немного и запустите снова.

3. **Дубликаты**: Скрипт автоматически удаляет дубликаты вакансий.

4. **Время выполнения**: Сбор всех вакансий может занять 30-60 минут в зависимости от количества категорий и региона.

## ❓ Проблемы и решения

### Ошибка: "Connection timeout"
**Решение**: Проверьте интернет-соединение. Можете увеличить `timeout` в коде.

### Ошибка: "Too many requests"
**Решение**: Увеличьте задержку `self.delay_seconds` в классе `HHVacancyScraper`.

### Мало вакансий собралось
**Решение**: 
- Проверьте, что категории в `FINANCIAL_CATEGORIES` актуальны
- Попробуйте изменить регион поиска
- Увеличьте `max_per_category`
